## 功能与下载速查

京豆 Android 桌面小部件：多账号、Cookie 获取、京豆收益图表、东东农场进度和外观设置；源码工程。

### 下载到另一台电脑

- [下载源码 ZIP](https://github.com/lucc1832/AJingBeanAppWidget/archive/refs/heads/master.zip)，或在仓库页面选择 **Code → Download ZIP**。
- 使用 GitHub CLI：`gh repo clone lucc1832/AJingBeanAppWidget`。
- 整理时未发现本仓库 Releases 的安装包附件；上述 ZIP 是源码/资料，不是现成安装包。原说明中的其他下载入口见下文。

### 使用与迁移

使用 Android Studio 构建，安装后配置自己的账号；依赖京东相关接口。README 中未勾选的功能不算已实现。

说明依据本仓库文档与源码整理于 2026-09-23；此次整理未运行应用或活动脚本。

# JingBeanAppWidget
![APP](https://cdn.jsdelivr.net/gh/baifan97/JingBeanAppWidget/APP.png)
京豆，无多余内容，完全开源，可基于源码进行二次打包，但请保留开源信息。

## 功能
- [x] 一键获取`Cookie`
- [x] 多账号管理
- [x] 4*2小部件支持`简版展示`和`柱状图展示`
- [x] 2*2小部件支持`京豆收益展示`和`东东农场数据展示`
- [x] 背景色、边距等更多自定义功能设置
- [x] APP跟随系统深色模式
- [x] 手机/平板（竖屏/横屏）界面适配
- [ ] 用户日资产卡片（正式版中此功能已上线）
- [ ] 小部件跟随系统深色模式（正式版中此功能已上线）
- [ ] 各种助力脚本执行
- [ ] 多账号资产详情查询页面
